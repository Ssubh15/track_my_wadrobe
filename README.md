# Wardrobe

An iOS wardrobe app. This repository currently contains only the agreed project structure and product documentation. No app implementation has been added.

## Planned stack

- Swift 5.9+ and SwiftUI
- iOS 17+
- SwiftData, Vision, Core Image, Core ML, PhotosUI, AVFoundation
- CloudKit behind a future feature flag

See [the product requirements](docs/PRD.md) and [project structure](docs/STRUCTURE.md).
